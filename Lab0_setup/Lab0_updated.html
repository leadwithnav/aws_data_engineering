Module 1: Overview & Architecture

Setting up workstation tools, Kubernetes engines, and AWS cloud runtimes.

💡 Skip Installed Tools

If any software tool (such as Git, Docker, Python, or AWS CLI) is already installed on your system and passes its verification command, you do NOT need to reinstall it. Run the verification test command and mark the task as complete!

Workstation & Tooling Architecture

This course relies on a local containerized data engineering workstation setup:

  • Local Development: Docker Desktop, Minikube, JDK 17, and PySpark client tools.
  • Container Orchestration: Local Kubernetes clusters managed via kubectl and minikube.
  • Review Prerequisites & Architecture Verify system requirements and understand the developer workstation architecture.

Module 4: Big Data Runtimes

Java Development Kit (JDK 17) and Apache Spark Client 3.5.1.

⚠️ Java 17 Version Requirement

Apache Spark 3.5.x strictly requires JDK 17. Versions newer than Java 17 (such as JDK 21) trigger internal reflection errors during spark-submit.

4.1 Java Development Kit (JDK 17)

PowerShell
winget install EclipseAdoptium.Temurin.17.JDK
macOS Terminal
brew install openjdk@17
sudo ln -sfn /opt/homebrew/opt/openjdk@17/libexec/openjdk.jdk /Library/Java/JavaVirtualMachines/openjdk-17.jdk
echo 'export JAVA_HOME=$(/usr/libexec/java_home -v 17)' >> ~/.zshrc
echo 'export PATH="$JAVA_HOME/bin:$PATH"' >> ~/.zshrc
source ~/.zshrc
Linux Terminal
sudo apt install -y openjdk-17-jdk
echo 'export JAVA_HOME=/usr/lib/jvm/java-17-openjdk-amd64' >> ~/.bashrc
echo 'export PATH="$JAVA_HOME/bin:$PATH"' >> ~/.bashrc
source ~/.bashrc

Verification Command:

Test Step
java -version

4.2 Apache Spark Client (v3.5.1)

PowerShell
Invoke-WebRequest -Uri "https://archive.apache.org/dist/spark/spark-3.5.1/spark-3.5.1-bin-hadoop3.tgz" -OutFile "spark-3.5.1-bin-hadoop3.tgz"
tar -xzf spark-3.5.1-bin-hadoop3.tgz
[System.Environment]::SetEnvironmentVariable('SPARK_HOME', 'D:\spark-3.5.1-bin-hadoop3', 'User')
$env:PATH += ";D:\spark-3.5.1-bin-hadoop3\bin"
macOS Terminal
curl -O https://archive.apache.org/dist/spark/spark-3.5.1/spark-3.5.1-bin-hadoop3.tgz
mkdir -p ~/spark && tar -xzf spark-3.5.1-bin-hadoop3.tgz -C ~/spark
echo 'export SPARK_HOME=$HOME/spark/spark-3.5.1-bin-hadoop3' >> ~/.zshrc
echo 'export PATH="$SPARK_HOME/bin:$PATH"' >> ~/.zshrc
source ~/.zshrc
Linux Terminal
curl -O https://archive.apache.org/dist/spark/spark-3.5.1/spark-3.5.1-bin-hadoop3.tgz
mkdir -p ~/spark && tar -xzf spark-3.5.1-bin-hadoop3.tgz -C ~/spark
echo 'export SPARK_HOME=$HOME/spark/spark-3.5.1-bin-hadoop3' >> ~/.bashrc
echo 'export PATH="$SPARK_HOME/bin:$PATH"' >> ~/.bashrc
source ~/.bashrc

Verification Command:

Test Step
spark-submit --version
  • Verify Java 17 & Spark 3.5.1 Confirm `java -version` prints 17.0.x and `spark-submit --version` displays Spark 3.5.1.
