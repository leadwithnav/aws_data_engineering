Module 2: Containerize Spark App

Bundling PySpark script and Hadoop AWS S3 connector JARs into Docker.

1. PySpark Application (`app/spark_app.py`)

Python Code (spark_app.py)
import os, sys
from pyspark.sql import SparkSession
from pyspark.sql.functions import col, sum as _sum, count, round as _round

def main():
    spark = SparkSession.builder \
        .appName("SparkMinikubeDemo") \
        .getOrCreate()
    
    spark.sparkContext.setLogLevel("ERROR")
    
    s3_bucket = os.environ.get("S3_BUCKET", "")
    if s3_bucket:
        input_path = f"s3a://{s3_bucket}/sample_data.csv"
        output_path = f"s3a://{s3_bucket}/spark-output/"
    else:
        input_path = "/opt/spark/work-dir/sample_data.csv"
        output_path = None

    print(f"Reading transaction data from {input_path}...")
    df = spark.read.csv(input_path, header=True, inferSchema=True)
    
    agg_df = df.groupBy("Category").agg(
        count("OrderID").alias("TotalOrders"),
        _round(_sum("Amount"), 2).alias("TotalRevenue")
    ).orderBy(col("TotalRevenue").desc())
    
    agg_df.show()
    
    if output_path:
        print(f"Writing parquet output to {output_path}...")
        agg_df.write.mode("overwrite").parquet(output_path)
        print("Parquet write complete!")

    spark.stop()

if __name__ == "__main__":
    main()

2. Dockerfile with AWS S3 JARs (`app/Dockerfile`)

Dockerfile
FROM apache/spark:3.5.1

USER root

# Download Hadoop AWS and AWS SDK bundle JARs into Spark jars directory
ADD https://repo1.maven.org/maven2/org/apache/hadoop/hadoop-aws/3.3.4/hadoop-aws-3.3.4.jar /opt/spark/jars/
ADD https://repo1.maven.org/maven2/com/amazonaws/aws-java-sdk-bundle/1.12.262/aws-java-sdk-bundle-1.12.262.jar /opt/spark/jars/

WORKDIR /opt/spark/work-dir

COPY spark_app.py /opt/spark/work-dir/
COPY sample_data.csv /opt/spark/work-dir/

RUN chown -R 185:185 /opt/spark/work-dir /opt/spark/jars

USER 185

Module 3: Load Image into Minikube

Transferring local container images into Minikube's internal registry cache.

Minikube CLI
# Load image into Minikube
minikube image load spark-on-minikube:latest

# Verify image exists in cluster cache
minikube image ls | grep "spark-on-minikube"
  • Cache Image in Minikube Execute `minikube image load` and confirm image presence in the cluster registry.

Module 5: S3 Integration Flow

Passing local AWS IAM credentials to Spark K8s pods to read and write S3 bucket data.

1. Upload Dataset to Amazon S3

AWS CLI
aws s3 mb "s3://YOUR_UNIQUE_BUCKET_NAME" --region us-east-1
aws s3 cp "app/sample_data.csv" "s3://YOUR_UNIQUE_BUCKET_NAME/sample_data.csv"

2. Submit S3 Job with Local Credentials

PowerShell
.\local\submit_spark_minikube.ps1 -b "YOUR_UNIQUE_BUCKET_NAME"
Terminal
./local/submit_spark_minikube.sh -b "YOUR_UNIQUE_BUCKET_NAME"

3. Verify S3 Parquet Output

AWS CLI
aws s3 ls "s3://YOUR_UNIQUE_BUCKET_NAME/spark-output/"
