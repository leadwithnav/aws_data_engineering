Module 1: Overview & Architecture

Repelling general workloads with Taints & allowing execution with Tolerations.

💡 Learning Objective

Configure Taints and Tolerations on a 3-node local Minikube cluster. Reserve dedicated node resources (`minikube-m03`) for data engineering workloads (Apache Spark), repel general workloads (Python Flask app) from scheduling on tainted nodes, and configure matching pod tolerations to grant access to dedicated hardware.

Taints vs Tolerations Scheduling Architecture

  • Review Taints & Tolerations Concepts Understand how taints repel pods lacking matching tolerations while `NoSchedule` protects hardware resources.

Module 3: Taint & Label Reserved Node (`minikube-m03`)

Attaching repelling taints and targeting labels to node minikube-m03.

1. Apply Taint (`dedicated=spark:NoSchedule`)

Kubectl CLI
kubectl taint nodes minikube-m03 dedicated=spark:NoSchedule

2. Apply Node Label (`dedicated=spark`)

Kubectl CLI
kubectl label nodes minikube-m03 dedicated=spark

3. Verify Node Taint Details

Kubectl CLI
kubectl describe node minikube-m03 | grep "Taints:"

Module 5: Submit Spark Job with Tolerations

Configuring matching tolerations to grant Spark pods access to reserved nodes.

1. Examine Spark Pod Templates

Kubernetes YAML (Tolerations Spec)
spec:
  nodeSelector:
    dedicated: spark
  tolerations:
    - key: "dedicated"
      operator: "Equal"
      value: "spark"
      effect: "NoSchedule"

2. Configure RBAC & Load Spark Image

Kubectl & Minikube CLI
kubectl apply -f spark-rbac.yaml
minikube image load spark-on-eks:latest

3. Submit Spark Job with Toleration Templates

PowerShell
$K8S_MASTER = (kubectl config view --minify -o jsonpath='{.clusters[0].cluster.server}')

spark-submit `
  --master "k8s://$K8S_MASTER" `
  --deploy-mode cluster `
  --name spark-taint-demo `
  --conf spark.kubernetes.container.image=spark-on-eks:latest `
  --conf spark.kubernetes.authenticate.driver.serviceAccountName=spark `
  --conf spark.executor.instances=2 `
  --conf spark.kubernetes.driver.podTemplateFile=d:\trainings\aws_data_engineering\k8s_taint_toleration_lab\manifests\spark-driver-template.yaml `
  --conf spark.kubernetes.executor.podTemplateFile=d:\trainings\aws_data_engineering\k8s_taint_toleration_lab\manifests\spark-executor-template.yaml `
  local:///opt/spark/work-dir/spark_app.py `
  local:///opt/spark/work-dir/sample_data.csv
Terminal
export K8S_MASTER=$(kubectl config view --minify -o jsonpath='{.clusters[0].cluster.server}')

spark-submit \
  --master "k8s://$K8S_MASTER" \
  --deploy-mode cluster \
  --name spark-taint-demo \
  --conf spark.kubernetes.container.image=spark-on-eks:latest \
  --conf spark.kubernetes.authenticate.driver.serviceAccountName=spark \
  --conf spark.executor.instances=2 \
  --conf spark.kubernetes.driver.podTemplateFile=~/trainings/aws_data_engineering/k8s_taint_toleration_lab/manifests/spark-driver-template.yaml \
  --conf spark.kubernetes.executor.podTemplateFile=~/trainings/aws_data_engineering/k8s_taint_toleration_lab/manifests/spark-executor-template.yaml \
  local:///opt/spark/work-dir/spark_app.py \
  local:///opt/spark/work-dir/sample_data.csv

Module 7: Cleanup & Remove Taints

Restoring default cluster scheduling state and removing node taints.

1. Delete Workload Deployments

Kubectl CLI
kubectl delete -f manifests/flask-deployment.yaml
kubectl delete pod --all

2. Remove Node Taint (Trailing Minus `-`)

Kubectl CLI
kubectl taint nodes minikube-m03 dedicated:NoSchedule-

3. Remove Node Label (Trailing Minus `-`)

Kubectl CLI
kubectl label nodes minikube-m03 dedicated-

4. Stop Minikube Cluster

Minikube CLI
minikube stop
  • Remove Taint & Stop Minikube Remove node taint using `dedicated:NoSchedule-`, remove node label using `dedicated-`, and stop cluster.
