1. Flask Application (`app/app.py`)

Inspect the web application code exposing diagnostic system information:

Python Code (app.py)
import os
import socket
import datetime
from flask import Flask, jsonify

app = Flask(__name__)

@app.route('/')
def home():
    return jsonify({
        "message": "Welcome to the Containerized Flask Application!",
        "status": "online",
        "hostname": socket.gethostname(),
        "ip_address": socket.gethostbyname(socket.gethostname()),
        "timestamp": datetime.datetime.now().isoformat()
    })

@app.route('/health')
def health():
    return jsonify({"status": "healthy", "service": "flask-web"})

if __name__ == '__main__':
    # Local development server (Gunicorn will run the app in production)
    app.run(host='0.0.0.0', port=5000, debug=True)

Module 3: Dockerfile & Security

Constructing a layered, secure Dockerfile with non-root user privileges.

Production Dockerfile (`app/Dockerfile`)

Dockerfile
# Use an official lightweight Python runtime as base image
FROM python:3.11-slim

# Set environment variables for Python
ENV PYTHONDONTWRITEBYTECODE=1
ENV PYTHONUNBUFFERED=1
ENV APP_ENV=production

# Set working directory inside container
WORKDIR /app

# Copy requirements.txt first to exploit Docker layer caching
COPY requirements.txt .

# Install dependencies without package caching to reduce image size
RUN pip install --no-cache-dir -r requirements.txt

# Copy Flask application source code
COPY app.py .

# Create a non-root group and user for security hardening
RUN groupadd -g 10001 appgroup && useradd -u 10001 -g appgroup -m -s /bin/bash flaskuser

# Set ownership of app directory
RUN chown -R flaskuser:appgroup /app

# Switch to non-root user
USER flaskuser

# Document that container listens on port 5000
EXPOSE 5000

# Launch application with Gunicorn WSGI server
CMD ["gunicorn", "--bind", "0.0.0.0:5000", "app:app"]

Dockerfile Best Practices Summary

Instruction Production Best Practice
python:3.11-slim Reduces overall image size compared to full Debian base images.
COPY requirements.txt . Placed before code copy to leverage Docker layer caching when dependencies don't change.
USER flaskuser Restricts container process privileges to prevent root escalation attacks.
CMD Gunicorn Deploys production multi-worker WSGI server listening on 0.0.0.0:5000.
  • Create and Configure Dockerfile Set base image, layer ordering, non-root user creation, and Gunicorn CMD instruction.

2. Container Diagnostic Commands

Docker CLI
# Check application stdout/stderr logs
docker logs flask-web

# Verify active non-root execution identity (returns "flaskuser")
docker exec flask-web whoami

# Inspect running processes inside container
docker top flask-web

# Stop and remove container
docker stop flask-web
docker rm flask-web
